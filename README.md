# Last Boss Games (LBG)

Last Boss Games adalah platform katalog web yang dirancang khusus untuk mempermudah pencarian dan pengunduhan permainan video serta ROM (termasuk PS2, PSP, PC, dan konsol retro). Platform ini menggunakan antarmuka bergaya *Neo-Brutalist* yang lugas, cepat, dan responsif.

## Fitur Utama

- **Pencarian dan Penyaringan Cepat:** Temukan permainan secara presisi menggunakan kata kunci, atau saring berdasarkan platform, genre, dan wilayah rilis.
- **Urutan Dinamis:** Jelajahi daftar permainan yang baru saja ditambahkan ke pangkalan data, atau urutkan berdasarkan skor popularitas tertinggi.
- **Desain Responsif:** Tata letak kartu poster dan navigasi menyesuaikan secara otomatis dengan ukuran layar perangkat Anda (PC maupun seluler).
- **Manajemen Konten Terpusat:** Penambahan dan pengeditan data permainan dikelola sepenuhnya melalui panel dasbor terpisah, yang otomatis memperbarui situs web secara waktu nyata (real-time).

## Teknologi Utama

Proyek ini dibangun menggunakan teknologi berikut:
- **Antarmuka Pengguna:** React (Vite) dan Tailwind CSS.
- **Basis Data & Manajemen Konten:** Sanity CMS.
- **Infrastruktur & Hosting:** Vercel (dilengkapi dengan pembaruan otomatis melalui *Webhooks*).
